## Modifying Rates

If you need to change pricing or minimum stay rules:
1. Open the corresponding villa markdown file in this folder to keep your documentation up to date.
2. Update the matching rate rows inside the code file [components/BookingWidget.tsx](file:///Users/dylanfarmer/Documents/Tropical%20Website/components/BookingWidget.tsx).
